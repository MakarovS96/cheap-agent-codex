description: Clean up expired Cheap Agent jobs and worktrees when the user requests Cheap Agent cleanup.

Use the cheapag MCP cleanup tool if advertised by the connected server; otherwise inspect `cheapag codex clean` usage and run its supported cleanup command in the requested repository. Explain which expired artifacts were removed and preserve active jobs, repository source, credentials and consent. Do not substitute blanket recursive deletion for the package's retention-aware cleanup.
